# 前端视觉优化设计文档

日期：2026-07-26
范围：frontend 全部页面。目标：以 Claude 桌面端为参照的视觉升级；普通用户视图零技术术语；登录/注册页增加动效与光效。约束：不新增任何 npm 依赖（纯 Tailwind + CSS + 现有 ECharts/lucide），保持现有路由与组件契约，`tsc --noEmit` 零错误。

## 1. 设计方向

参照 Claude 桌面端的三个核心特征：**暖色纸感**（米白背景而非冷灰，内容像放在纸上而不是仪表盘里）、**低对比度的安静界面**（极轻的边框与阴影，颜色只在需要注意的地方出现）、**大圆角与充足留白**（卡片 16px 圆角、行距宽松，信息不拥挤）。当前的"驾驶舱"风格（石墨 + 青色荧光 + 网格底纹 + 扫描线）整体替换。

## 2. 设计令牌（tailwind.config.js + styles.css）

**色彩。** 背景 `--bg: #FAF9F5`（暖米白）；面板 `#FFFFFF`；主色（accent）`#C96442` 一系（hover `#B55535`、浅底 `#F5E8E2`、文字对比通过深度控制）；中性色改用 Tailwind `stone` 系（暖灰）替换现有 `slate`（冷灰）；语义色 success `#7D9B76`（灰绿）、warning `#D4A27F`、danger `#C14C3D`，全部降饱和以贴合暖色纸感。信息层级靠 stone-900/stone-500/stone-400 三档文字色表达，不再用青色高亮。

**形状与阴影。** 卡片圆角 16px（`rounded-2xl`）、控件 10px、气泡 18px；阴影只保留两档：`shadow-soft: 0 1px 3px rgba(28,25,23,.06), 0 4px 16px rgba(28,25,23,.04)` 与悬浮态 `shadow-lift`（略深）。删除 `shadow-cockpit` 的重投影和 `line` 内描边。网格底纹删除，背景为纯色 + 页面顶部一层极淡的暖色径向渐变（光从上方来的纸感）。

**字体与数字。** 字体栈 `"PingFang SC", "Microsoft YaHei", "Segoe UI", system-ui`（去掉 Inter 优先，中文为主的产品应让中文字体决定排版）；所有表格与 KPI 数值 `font-variant-numeric: tabular-nums`；等宽保留 JetBrains Mono 仅用于查询语句展示。

**组件类重写。** `.panel`→白底/1px stone-200 边框/rounded-2xl/shadow-soft；`.control`→stone 边框、focus 环改主色 `rgba(201,100,66,.18)`；`.primary-btn`→主色实底、hover 加深并轻微上浮（translateY(-1px) + shadow-lift）；`.secondary-btn`→白底 stone 边框、hover 变主色浅底。`.code-block` 由黑底青字改为 `#FAF7F2` 暖纸底 + stone-700 文字 + 主色关键字（自研正则高亮，无新依赖）。

## 3. 术语最小化

原则：**默认视图零术语；技术细节渐进披露；开发者信息需要显式展开**。普通用户看到的是"问题 → 答案 → 图表"，其余一切收起。

改名与隐藏对照：

- 详情 tab："SQL" → "查询语句"；"执行过程" → "分析过程"；"来源" → "数据来源"。tab 区默认收起不变，入口文案由图标+术语改为一个安静的"查看分析详情"。
- 路径徽标（cold_path / rewrite_path / fast_path / memory hit 等内部枚举）在普通视图完全不展示；分析过程 tab 内译为人话："全新分析" / "参考历史经验" / "复用已验证查询"。
- TrustPanel 的 Guard/校验术语 → "数据保障"：语句只读、行数上限、字段白名单等以图标+短句表达（如"仅读取数据，不做任何修改"），不出现 Guard/LIMIT/whitelist 字样。
- 模型名与 provider（qwen…/aliyun/local）不在普通视图出现；移入分析过程 tab 底部的小字。
- DeveloperTracePanel 与原始 trace JSON：移入"分析过程"内一个"开发者信息"折叠段，默认收起。
- 阶段名保持业务语言（理解问题/检索口径/生成查询/校验执行/整理结果），错误文案检查一遍：不出现 Guard、EXPLAIN、SQL 拒绝等词，统一为"这次没有生成可靠的查询，换个问法试试"式表达（仅前端文案层，不改后端返回）。
- 顶部状态栏的"引擎在线"类 cockpit 文案 → 简化为一个绿点 + "服务正常"。

## 4. 页面方案

**应用外壳。** Sidebar：白底、当前项主色浅底 + 左侧 3px 主色条、图标 stone-500；产品名用文字标识（去掉 Database 图标的"数据库感"）。TopStatusBar 减薄，仅面包屑 + 状态点 + 用户菜单。整体内容区最大宽度约束，避免超宽拉伸。

**Chat。** 用户气泡主色浅底右对齐、助手内容白卡片；KPI 卡片大数字 + 小标签 + tabular-nums；图表统一注册暖色 ECharts 主题（见 §6）；流式进度条改为竖向 stepper：完成项打勾（灰绿）、当前项主色呼吸点、显示秒数。

**普通页面（指标/历史/设置/个人）。** 统一"页头（标题+一句话说明）+ 卡片"结构，表格行 hover 用 stone-50，分页与空态样式统一。这些页面只做令牌层面的被动升级，不重排布局。

## 5. 登录/注册：动效与光效

背景：深暖色夜空底（`#1C1917` 向 `#292524` 渐变），叠三个大尺寸模糊光斑（radial-gradient：主色橘、琥珀、玫瑰各一），以 `blob` 关键帧做 18–26 秒极慢漂移 + 缩放，`filter: blur(90px)`，透明度 0.25–0.4 —— 形成"极光"流动感。再叠一层极淡的 conic-gradient 慢旋光晕在卡片后方，让卡片像被打了一盏柔光。

卡片：玻璃拟态 `bg-white/[0.08] backdrop-blur-xl border-white/15 rounded-3xl`，顶部 1px 高光描边（`border-top-color: rgba(255,255,255,.28)`）。入场动画：卡片 fade + 上移 480ms，内部元素（标题/输入框/按钮）以 60ms 间隔 stagger 进入。

微交互：输入框 focus 时边框过渡到主色光环；主按钮 hover 有一道 45° 光泽扫过（伪元素 translateX 动画）；提交中按钮内嵌旋转 loader；错误提示 shake 一次（240ms）。左右分栏的品牌侧改为一句产品价值文案 + 三条特性（自然语言提问/安全只读/结果可追溯），不出现任何技术词。

无障碍：全部动效包在现有 `prefers-reduced-motion` 保护内（样式表已有全局降级，保留）；光斑层 `pointer-events: none`；对比度保证表单文字 ≥ 4.5:1。

## 6. ECharts 暖色主题

`registerTheme('warm', …)`：分类色板 `['#C96442','#7D9B76','#D4A27F','#8B7E74','#A8763E','#5E7B8B']`；轴标签 stone-400、splitLine 虚线 `#E7E5E4`、去 y 轴线；柱条 `borderRadius:[4,4,0,0]`；折线 smooth + 8% 透明度渐变面积；tooltip 白底圆角软阴影。Chart 包装组件统一应用，业务组件零改动。

## 7. 动效规范

时长：微交互 150–200ms、面板展开 240ms、页面入场 420–480ms；缓动统一 `cubic-bezier(0.2, 0.8, 0.2, 1)`；hover 只动 color/shadow/transform（不触发重排）；除登录页光斑与状态呼吸点外，不做无限循环动画。

## 8. 实施与验收

改动文件：tailwind.config.js、styles.css（令牌与组件类、登录页动效关键帧）、Chart.tsx（主题注册）、LoginPage/RegisterPage（重写视觉层）、Sidebar/TopStatusBar/AppLayout、chat 组件五件套与 data-qa 面板（术语文案 + 令牌）、其余页面被动升级。验收：`tsc --noEmit` 零错误（沙箱 + 本机各跑一次）；术语走查——以普通用户身份过一遍主流程，页面上不得出现 SQL/Guard/cold_path/模型名/provider 字样（详情展开区除外，且展开区也使用 §3 的译名）；`prefers-reduced-motion` 下登录页静止可用。
